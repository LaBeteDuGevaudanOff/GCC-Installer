## 📖 О проекте

**MinGW GCC Suite & C-LibManager** — это готовое окружение для комфортной разработки на языке **C/C++** под Windows. Проект объединяет в себе свежую портативную сборку компилятора **MinGW-w64 GCC** (с поддержкой C, C++, GDB, Make и Win32 API) и легковесный графический контроллер зависимостей **C-LibManager** на базе .NET 8 и Avalonia UI.

> [!TIP]
> Больше не нужно вручную скачивать архивы, копировать `.h` файлы в `include`, линковать `.a` в `lib` и мучиться с флагами сборки в терминале — всё управляется в 1 клик!

## 🚀 Варианты установки

В разделе **Releases** доступны две версии инсталлятора:

| Инсталлятор | Размер | Описание |
| :--- | :--- | :--- |
| **`MinGW_GCC_Web_Setup.exe`** | `~46 МБ` | **Компактная Web-версия.** Загружает графический менеджер, а сам компилятор GCC автоматически скачивает во время установки. |
| **`MinGW_GCC_Offline_Setup.exe`** | `~80 МБ` | **Полная автономная версия.** Включает GCC, менеджер и базовые библиотеки. Устанавливается мгновенно без доступа к интернету. |

### 🛠️ Процесс установки

1. Запустите выбранный `.exe` установщик от имени **администратора**.
2. Выберите тип установки:
   - **Полная:** компилятор GCC + контроллер C-LibManager + все библиотеки.
   - **Чистая (Compact):** только GCC и C-LibManager без сторонних библиотек.
   - **Выборочная:** самостоятельная настройка необходимых библиотек галочками.
3. Установщик автоматически пропишет `C:\MinGW\bin` в системную переменную `PATH` и создаст ярлыки на рабочем столе.
4. По завершении C-LibManager запустится автоматически.

## ✨ Возможности C-LibManager

- 🧠 **Интеллектуальная детекция компилятора:** Определяет системный GCC через команды окружения, парсит версию и привязывается к рабочим путям.
- ☁️ **Каталог библиотек из облака:** Список доступных пакетов загружается напрямую из GitHub-репозитория и кэшируется для мгновенного доступа без зависаний.
- ⚡ **Установка и удаление в 1 клик:** Автоматическое скачивание, безопасное копирование файлов в `include/` и `lib/`, а также ведение локального журнала.
- 📦 **Drag-and-Drop ручная установка:** Можно просто перетащить любой сторонний архив (`.zip`) или файл (`.h`, `.a`, `.dll`) в окно программы — менеджер сам распознает структуру и разложит зависимости.
- 🔍 **Сканер локального окружения:** Отображает все библиотеки, уже присутствующие в вашей системе и компиляторе, даже если их нет в удаленном каталоге.
- 📋 **Копирование флагов GCC:** Возле каждой библиотеки указаны точные флаги линковщика для компиляции с кнопкой мгновенного копирования в буфер обмена.
- 🧹 **Полная очистка (Wipe):** Возможность при необходимости вычистить весь компилятор и библиотеки с диска.
